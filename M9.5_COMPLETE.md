**Added to `src/backends/directx/dx12_impl.rs`:**

```rust
struct DirectXPassContext {
    command_list: *mut (),  // Raw pointer pattern like Vulkan/wgpu
}

impl PassExecutionContext for DirectXPassContext {
    fn bind_vertex_buffer(...) { /* ID3D12GraphicsCommandList::IASetVertexBuffers */ }
    fn bind_index_buffer(...) { /* ID3D12GraphicsCommandList::IASetIndexBuffer */ }
    fn draw(...) { /* ID3D12GraphicsCommandList::DrawInstanced */ }
    fn draw_indexed(...) { /* ID3D12GraphicsCommandList::DrawIndexedInstanced */ }
}
```

**Updated execute_graph():**
- Changed from hardcoded `command_list.DrawInstanced(3, 1, 0, 0)` 
- Now calls `pass.callback.execute(&mut context)`
- Creates DirectXPassContext for each pass
- Properly executes pass callbacks

## Technical Details

### DirectX Implementation Notes

**Vertex Stride:**
- Currently hardcoded to 48 bytes (sizeof(Vertex))
- TODO: Should pass stride through BufferDescriptor or separate API
- Works for current triangle example

**Pattern Consistency:**
- Uses same raw pointer pattern as Vulkan and wgpu
- Same safety considerations (pointer only dereferenced during pass execution)
- Matches architecture across all backends

**Buffer Access:**
- Downcasts `*const c_void` to `*const DirectXBuffer`
- Accesses `resource: ID3D12Resource` directly
- Uses `GetGPUVirtualAddress()` for GPU pointer
