# M8.3: Shader Resource Binding - Implementation Plan

**Date:** 2025-10-19  
**Status:** Planning  
**Goal:** Implement descriptor sets/bind groups for uniform buffers and textures

## Overview

M8.3 adds the ability to bind shader resources (uniform buffers, textures, samplers) to the rendering pipeline. This is essential for:
- Camera/view matrices
- Model transforms  
- Material parameters
- Texture sampling

## Architecture Design

### 1. Backend-Agnostic Abstraction

```rust
// Core binding abstraction
pub enum ShaderBinding {
    UniformBuffer {
        binding: u32,
        size: u64,
        stage: ShaderStage,
    },
    Texture {
        binding: u32,
        dimension: TextureDimension,
        stage: ShaderStage,
    },
    Sampler {
        binding: u32,
        stage: ShaderStage,
    },
}

pub struct BindGroupLayout {
    bindings: Vec<ShaderBinding>,
}

pub struct BindGroup {
    layout: BindGroupLayout,
    resources: Vec<BoundResource>,
}

pub enum BoundResource {
    UniformBuffer(Arc<dyn Buffer>),
    Texture(Arc<dyn Texture>),
    Sampler(Arc<dyn Sampler>),
}
```

### 2. Backend Implementations

**Vulkan:**
- `VkDescriptorSetLayout` for layouts
- `VkDescriptorPool` for allocation
- `VkDescriptorSet` for bindings
- `vkUpdateDescriptorSets` for resource binding

**wgpu:**
- `BindGroupLayout` (native wgpu concept)
- `BindGroup` (native wgpu concept)
- Direct mapping to our abstractions

**DirectX 12:**
- Root signature for layout
- Descriptor heaps for resources
- Root parameter binding

### 3. Uniform Buffer Support

```rust
pub trait UniformBuffer: Buffer {
    fn update(&mut self, data: &[u8], offset: u64) -> Result<()>;
    fn map(&mut self) -> Result<&mut [u8]>;
    fn unmap(&mut self);
}

// Example usage
struct CameraUniforms {
    view: Mat4,
    projection: Mat4,
}

impl CameraUniforms {
    fn as_bytes(&self) -> &[u8] {
        bytemuck::bytes_of(self)
    }
}
```

### 4. Sampler Support

```rust
pub enum FilterMode {
    Nearest,
    Linear,
}

pub enum AddressMode {
    Repeat,
    ClampToEdge,
    ClampToBorder,
    MirroredRepeat,
}

pub struct SamplerDescriptor {
    pub mag_filter: FilterMode,
    pub min_filter: FilterMode,
    pub mipmap_filter: FilterMode,
    pub address_mode_u: AddressMode,
    pub address_mode_v: AddressMode,
    pub address_mode_w: AddressMode,
    pub max_anisotropy: Option<u8>,
}

pub trait Backend {
    fn create_sampler(&mut self, desc: &SamplerDescriptor) -> Result<Arc<dyn Sampler>>;
}
```

## Implementation Steps

### Phase 1: Core Abstractions (2-3 hours)

**Files to create:**
- `src/backends/binding.rs` - BindGroup, BindGroupLayout
- `src/backends/sampler.rs` - Sampler trait and descriptor
- `src/backends/uniform.rs` - UniformBuffer trait

**Tasks:**
1. Define `ShaderBinding` enum with all resource types
2. Create `BindGroupLayout` for defining resource layouts
3. Create `BindGroup` for actual resource binding
4. Define `SamplerDescriptor` and `Sampler` trait
5. Add uniform buffer support to buffer trait

## Risks and Mitigations

**Risk:** DirectX 12 root signature complexity  
**Mitigation:** Start with simple static layouts, iterate

**Risk:** Vulkan descriptor pool management  
**Mitigation:** Use simple pooling strategy initially, optimize later

**Risk:** wgpu API differences  
**Mitigation:** Good abstraction layer will hide differences
