# M8.3: Pipeline Configuration Architecture

**Issue:** Vertex input state is currently hardcoded in the Vulkan backend, but different render passes need different configurations.

## Current Problem

```rust
// In VulkanBackend::create_pipeline() - HARDCODED!
let vertex_binding = vk::VertexInputBindingDescription::builder()
    .binding(0)
    .stride(Vertex::stride())
    .build();
```

This means:
- ❌ TrianglePass (hardcoded vertices) fails validation
- ❌ Future passes with different vertex layouts won't work
- ❌ Cannot load glTF models with custom vertex formats

## Solution: Pipeline Descriptor

Add pipeline configuration to RenderPass:

```rust
pub struct PipelineDescriptor {
    /// Vertex input layout (None = no vertex input)
    pub vertex_layout: Option<VertexBufferLayout>,
    
    /// Bind group layouts for shader resources
    pub bind_group_layouts: Vec<BindGroupLayout>,
    
    /// Shader modules
    pub vertex_shader: String,
    pub fragment_shader: String,
    
    /// Depth/stencil configuration
    pub depth_stencil: Option<DepthStencilState>,
    
    // Future: blend state, rasterizer state, etc.
}

pub struct RenderPass {
    // ... existing fields ...
    
    /// Optional pipeline configuration
    /// If None, uses backend's default pipeline
    pub pipeline_config: Option<PipelineDescriptor>,
}
```

## Usage Examples

### TrianglePass (Hardcoded Vertices)
```rust
let mut pass = RenderPass::new(pass_id, "triangle_pass", PassKind::Graphics);
// No vertex layout = shader uses hardcoded vertices
pass.pipeline_config = Some(PipelineDescriptor {
    vertex_layout: None,
    bind_group_layouts: vec![],
    vertex_shader: "triangle.vert".into(),
    fragment_shader: "triangle.frag".into(),
    depth_stencil: None,
});
```

### Vertex Buffer Pass (Using Vertex Struct)
```rust
let mut pass = RenderPass::new(pass_id, "mesh_pass", PassKind::Graphics);
pass.pipeline_config = Some(PipelineDescriptor {
    vertex_layout: Some(VertexBufferLayout::from_vertex::<Vertex>()),
    bind_group_layouts: vec![camera_layout, material_layout],
    vertex_shader: "mesh.vert".into(),
    fragment_shader: "pbr.frag".into(),
    depth_stencil: Some(DepthStencilState::default()),
});
```

### glTF Model Pass (Custom Vertex Format)
```rust
let vertex_layout = VertexBufferLayout {
    stride: 48,
    attributes: vec![
        VertexAttribute { location: 0, format: VertexFormat::Float32x3, offset: 0 },  // Position
        VertexAttribute { location: 1, format: VertexFormat::Float32x3, offset: 12 }, // Normal
        VertexAttribute { location: 2, format: VertexFormat::Float32x2, offset: 24 }, // UV0
        VertexAttribute { location: 3, format: VertexFormat::Float32x2, offset: 32 }, // UV1
        VertexAttribute { location: 4, format: VertexFormat::Float32x4, offset: 40 }, // Tangent
    ],
};

pass.pipeline_config = Some(PipelineDescriptor {
    vertex_layout: Some(vertex_layout),
    // ... rest of config
});
```
