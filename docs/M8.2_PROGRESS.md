**File**: `src/backends/vertex.rs`

- Defined standard `Vertex` struct (48 bytes):
  - `position: [f32; 3]` - 3D position
  - `normal: [f32; 3]` - Normal vector
  - `uv: [f32; 2]` - Texture coordinates
  - `color: [f32; 4]` - Vertex color (RGBA)
  
- Helper functions:
  - `Vertex::new()` - Create full vertex
  - `Vertex::new_2d()` - Convenience for 2D rendering
  - `Vertex::size()` - Get size in bytes (48)
  - `Vertex::stride()` - Get stride for vertex buffers (48)
  - `Vertex::attribute_descriptions_vulkan()` - Get attribute layout

- Supporting types:
  - `VertexFormat` enum (Float, Float2, Float3, Float4, UInt variants)
  - `VertexAttribute` - Attribute description with location, format, offset
  - `VertexBufferLayout` - Buffer binding description
  - `VertexInputRate` - Vertex or Instance input

## Technical Notes

### Vertex Memory Layout

The `Vertex` struct uses `#[repr(C)]` for predictable layout:
```
Offset 0:  position [f32; 3] = 12 bytes
Offset 12: normal   [f32; 3] = 12 bytes
Offset 24: uv       [f32; 2] = 8 bytes
Offset 32: color    [f32; 4] = 16 bytes
Total: 48 bytes
```

This matches the shader attribute offsets exactly.

### Coordinate System Handling

- **Vulkan**: Y points DOWN in NDC
- **wgpu**: Y points UP in NDC → Shaders flip Y
- **DirectX 12**: Y points UP in NDC → Shaders flip Y

All backends now read the same vertex data and produce consistent output through Y-flipping in shaders.

### Index Types

Both U16 and U32 are supported to allow:
- U16: Up to 65,535 vertices (smaller memory footprint)
- U32: Up to 4,294,967,295 vertices (for large models)
