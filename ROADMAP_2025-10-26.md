## 📚 Key Design Decisions

### Two-Backend Focus
**Decision**: Support Vulkan and DirectX 12 only  
**Rationale**: 
- Covers all major platforms (Linux, Windows)
- Depth over breadth
- Easier to maintain parity
- Forces good abstractions

### Data-Driven Rendering
**Decision**: All rendering configuration from files  
**Rationale**:
- No recompilation for scene changes
- Easy experimentation
- Clear separation of data and code
- Industry best practice

### Render Graph Architecture
**Decision**: Use render graph for all rendering  
**Rationale**:
- Automatic resource management
- Dependency resolution
- Flexible for complex pipelines
- Industry standard

### Scene Format (TOML)
**Decision**: Use TOML for scene files  
**Rationale**:
- Human-readable
- Easy to edit
- Good Rust support
- Suitable for configuration
